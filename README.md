# 社会ニーズ発見レーダー

社会に存在する不満、面倒な作業、企業の非効率、新しいニーズを記録し、将来の事業候補として整理するためのブラウザアプリです。

## 現在できること

* 課題のタイトル、詳しい内容、困っている人、支払者候補、情報源を手動登録できます。
* 登録した課題を一覧表示できます。
* 登録済みの課題を編集できます。
* 登録済みの課題を削除できます。
* データはブラウザの `localStorage` に保存されるため、同じブラウザではページを再読み込みしても残ります。
* 公開GitHubリポジトリの未完了Issueを最大30件取得し、保存前の課題候補として表示できます。
* Hacker Newsの投稿を検索し、保存前の課題候補として表示できます。
* 外部候補は内容と元ページを確認してから、1件ずつ課題として保存できます。

## 使い方

### 手動で課題を登録する

1. `index.html` をブラウザで開きます。
2. 左側のフォームに課題を入力します。
3. 「登録する」ボタンを押します。
4. 右側の一覧に登録した課題が表示されます。
5. 一覧の「編集」または「削除」ボタンで内容を変更できます。
6. 外部候補を保存する場合は、情報源を選び、GitHubなら「owner/repo」またはリポジトリURL、Hacker Newsなら検索語を入力して「候補を取得」を押します。

### 外部情報から課題候補を取得する

1. 「外部から課題候補を取得」で情報源を選びます。
2. GitHub Issuesの場合は `owner/repo` またはGitHubリポジトリURLを入力します。
3. Hacker Newsの場合は検索語を入力します。空欄なら既定の検索語で取得します。
4. 「候補を取得」ボタンを押します。
5. 表示された課題候補の内容と元ページを確認します。
6. 保存したい候補だけ「課題として保存」を押します。
7. 保存した候補は、既存の課題一覧に追加されます。同じ候補は再保存できません。

## 使用する外部API

GitHub REST APIのIssue一覧取得APIとHacker News Search API（Algolia）を使用します。

```text
https://api.github.com/repos/{owner}/{repo}/issues
https://hn.algolia.com/api/v1/search_by_date
```

今回は認証トークンを使用しません。APIキー、アクセストークン、パスワードなどの秘密情報は不要です。

## GitHub Pagesで公開する場合

このリポジトリは、追加のビルドなしで静的ファイルとして公開できます。

1. GitHubのリポジトリ設定を開きます。
2. Pagesの公開元をこのブランチのルートディレクトリにします。
3. 公開されたURLをSafariで開きます。

## 注意

* データはサーバーではなく、利用中のブラウザ内に保存されます。
* 別の端末や別のブラウザには自動同期されません。
* ブラウザのサイトデータを削除すると、保存した課題も消える可能性があります。
* GitHub Issuesの取り込みは公開リポジトリのみ対象です。認証なしで使うため、GitHub側のレート制限を受ける可能性があります。
* Hacker News検索はHN Search APIの公開データを使います。検索語によっては社会課題と関係の薄い投稿も候補に含まれます。
