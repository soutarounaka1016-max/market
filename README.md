# 社会ニーズ発見レーダー

社会に存在する不満、面倒な作業、企業の非効率、新しいニーズを記録し、将来の事業候補として整理するためのブラウザアプリです。

## 現在できること

* 課題のタイトル、詳しい内容、困っている人、支払者候補、情報源を登録できます。
* 登録した課題を一覧表示できます。
* 登録済みの課題を編集できます。
* 登録済みの課題を削除できます。
* データはブラウザの `localStorage` に保存されるため、同じブラウザではページを再読み込みしても残ります。
* 公開GitHubリポジトリの未完了Issueを最大30件取得し、課題候補として取り込めます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 左側のフォームに課題を入力します。
3. 「登録する」ボタンを押します。
4. 右側の一覧に登録した課題が表示されます。
5. 一覧の「編集」または「削除」ボタンで内容を変更できます。
6. GitHub Issuesから取り込む場合は、「owner/repo」またはGitHubのリポジトリURLを入力して「Issueを取得」を押します。

## GitHub Pagesで公開する場合

このリポジトリは、追加のビルドなしで静的ファイルとして公開できます。

1. GitHubのリポジトリ設定を開きます。
2. Pagesの公開元をこのブランチのルートディレクトリにします。
3. 公開されたURLをSafariで開きます。

## 注意

* データはサーバーではなく、利用中のブラウザ内に保存されます。
* 別の端末や別のブラウザには自動同期されません。
* ブラウザのサイトデータを削除すると、保存した課題も消える可能性があります。
* GitHub Issuesの取り込みは公開リポジトリのみ対象です。認証なしで使うため、GitHub側のレート制限を受ける可能性があります。
